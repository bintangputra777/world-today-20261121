## How to run

```sh

```

Needs Node 22+. The program copies `assets/entry.png` (1024×1024 PNG) to `/output/entry.png`, uses no network, and writes identical bytes on every run.

## Files

- `main.ts` — the entrypoint (copies the image to `/output/entry.png`)
- `assets/entry.png` — the rendered front page
- `scripts/render.py` — draws the image from the five stories
